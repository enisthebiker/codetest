# CodeTest

A simple online playground for writing, testing and formatting code.

CodeTest provides a lightweight workspace where you can experiment with HTML, CSS and JavaScript, preview your results instantly, and format your code when needed.

### Features

- **Code Playground:** Write and test HTML, CSS and JavaScript.
- **Live Preview:** See your code in action.
- **Console:** View JavaScript logs and errors.
- **Code Beautifier:** Format HTML, CSS, JavaScript and JSON.
- **Responsive Preview:** Test your designs in different screen sizes.
- **Download:** Save your work as an HTML file.

### Try it online

[Open CodeTest](https://enisthebiker.github.io/codetest/)

# CodeTest (Türkçe)

Kod yazmak, denemek ve biçimlendirmek için basit bir çevrimiçi çalışma alanı.

CodeTest, HTML, CSS ve JavaScript kodlarını yazıp deneyebileceğiniz, sonuçları anında önizleyebileceğiniz ve ihtiyaç duyduğunuzda kodlarınızı biçimlendirebileceğiniz hafif ve kullanışlı bir araçtır.

### Özellikler

- **Kod Editörü:** HTML, CSS ve JavaScript kodları yazıp çalıştırma.
- **Canlı Önizleme:** Kodların sonucunu anında görüntüleme.
- **Konsol:** JavaScript mesajlarını ve hatalarını görüntüleme.
- **Code Beautifier:** HTML, CSS, JavaScript ve JSON kodlarını biçimlendirme.
- **Farklı Ekran Boyutları:** Tasarımları masaüstü, tablet ve telefon boyutlarında test etme.
- **İndirme:** Çalışmanızı HTML dosyası olarak kaydetme.
